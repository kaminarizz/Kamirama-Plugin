O **Kamirama** é um repositório de providers para o Nuvio. Cada um percorre o
fluxo completo de metadados do TMDB, busca, matching, episódios, player e
extração de streams.

> Este repositório é feito para instalação: basta adicionar o manifest ao
> Nuvio.

---

## ⚡ Instalação no Nuvio

1. Abra o **Nuvio**.
2. Vá em **Configurações → Conteúdo e descoberta → Plugins**.
3. Escolha **Adicionar repositório**.
4. Cole esta URL:

   ```text
   https://raw.githubusercontent.com/kaminarizz/Kamirama-Plugin/main/manifest.json
   ```

5. Atualize a lista e habilite os providers desejados.

Para testar uma atualização, use **Refresh** na mesma tela do Nuvio.


---

## ⚖️ Aviso

O Kamirama não hospeda vídeos, arquivos de mídia ou servidores de streaming.
Os providers apenas acessam fontes públicas de terceiros. O uso é de
responsabilidade de cada pessoa e deve respeitar as leis aplicáveis.
